# Thai Todo

แอปรายการสิ่งที่ต้องทำ (React + Vite + Tailwind CSS + lucide-react)

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด dev server
npm run build    # build สำหรับ production (โฟลเดอร์ dist)
npm run preview  # ดูผลลัพธ์ที่ build แล้ว
```

ข้อมูลเก็บใน React state เท่านั้น รีเฟรชหน้าแล้วข้อมูลจะรีเซ็ต
